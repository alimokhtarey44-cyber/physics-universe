# ⚛️ Physics Universe — آزمایشگاه فیزیک سه‌بعدی

یک شبیه‌ساز تعاملی فیزیک با Three.js. هر آزمایش یک **ماژول مستقل** است؛ برای افزودن شاخه یا پدیده جدید فقط یک فایل اضافه می‌کنی.

## اجرا
```bash
npm install
npm run dev      # توسعه
npm run build    # خروجی در dist/
```
با push روی `main` و فعال‌کردن GitHub Pages (Source: GitHub Actions) سایت خودکار منتشر می‌شود.

## افزودن ماژول
فایل `src/modules/<دسته>/<نام>.js` بساز؛ خودکار ثبت می‌شود:
```js
import * as THREE from 'three';
import {ctx,scene,rb,Trail,lineOf,wl} from '../../core/helpers.js';

export default {
  cat:'mechanics', name:'🎯 نام آزمایش', d:26, tg:[0,0,0],   // دسته، عنوان، فاصله دوربین، نقطه هدف
  sum:'توضیح کوتاه', formula:'فرمول‌ها', num:'روش عددی و محدودیت مدل',
  params:[{k:'v',l:'سرعت',min:1,max:50,step:1,v:10,u:'m/s',w:'اگر زیاد شود چه می‌شود؟'}],
  why:['چرا؟','علت ۱','علت ۲'],
  acts:[{l:'دکمه اختیاری',f:()=>rb()}],
  build(){/* ساخت صحنه سه‌بعدی؛ پارامترها در this.p */},
  step(dt){/* پیشروی فیزیک (ثانیه) */},
  read(){return 'مقادیر زنده (HTML)'},
  onParam(k,oldV,newV){/* اختیاری */}
};
```
دسته‌ها در `src/modules/index.js` (آرایه `CATS`) تعریف شده‌اند.

## اصول علمی
هر ماژول باید فرمول، واحد SI، روش عددی و **محدودیت مدل** را صریح بنویسد؛ مدل تقریبی/آموزشی باید همین‌طور برچسب بخورد. بخش هسته‌ای فقط آموزش فیزیک (واپاشی، شکافت/راکتور مفهومی) است و شامل هیچ طراحی سلاح نمی‌شود.
